\# Cross Masonry



This app allows customer to write reviews. While viewing the app page for this company in particular. 



\## Screen 

* \*\*Home\*\* - This where customer can write their review message about the company.
* \*\*List\*\* - They can read and remove their messages about the company they have made.
* \*\*About\*\* - Customers can read about the company what they are they do for a living.



\## Input Rules



&#x20; | Input | What the app say |

* (nothing) | Add button greyed out
* "   " | Add button greyed out 
* I added over 30 character | Didn't allow me to enter anymore character 
* I added two letters | It said " too short - at least 3 characters" 
* duplicated item with different Capitals | It said "That message is already on the list" 
* Entered a string starting with a number "1hey" | It said "Start with a letter" 
* "Hey" | It added to list
* "Cross Masonry" | It added to list



\## How to run

1\. Clone this repo

2\. Open the cloned folder in Android Studio

3\. Wait for Gradle sync, then Run



\## Know Limitation

* When adding new messages from home page. You go and check them on the list page then rotate the screen the new messages disappear from the list.
